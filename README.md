# EhViewerNz

EhViewerNz 是基于 [Ehviewer_CN_SXJ](https://github.com/xiaojieonly/Ehviewer_CN_SXJ) 的 Fork.

## Fork 功能

### 快速保存

- 用于保存画廊中当前浏览的图片，方便将单张图片快速收藏到本地。
- 阅读图片时，可通过如下方式执行 `快速保存`：
  - 点击左下方 (`左侧 36%` × `底部 10%`) 的快速保存区域；
  - 长按屏幕两侧 `36%` 的向后翻页区域 (根据阅读方向变化)。
- 设置中提供“快速保存”开关；关闭后，快速保存区域执行原有的向左翻页操作，翻页区域长按与其他区域一致 (唤起长按菜单)。
- 可在 `设置 - 下载` 菜单的“手动保存图片路径”中设定快速保存的目标路径。

### 图片浏览

- 新增“双击放大”开关，默认关闭。
  - 关闭后，浏览图片时支持快速点击翻页。
  - 开启后，恢复原有的快速点击触发双击放大机制。
- 自动翻页改用毫秒值，默认 `2000 ms`。
  - 支持数值输入 `20 ~ 30000 ms`，或通过滑动条设置 `100 ~ 15000 ms`。

### 画廊详情

- 新增“作者”按钮，点击后自动搜索，其关键词获取逻辑如下：
  - 优先使用第一个 `artist:` 标签，其次使用第一个 `cosplayer:` 标签；
  - 若无对应标签，则使用标题中 `[]`、`()` 等括号内清理后的内容。

- 页面最下方的“查看更多预览”按钮，可通过 `设置 - EH - 画廊预览立即跳转` 决定是否直接跳转至新内容（第二页）。
- 画廊详情页支持向左滑动快速进入画廊预览；
- 画廊预览支持双指缩放，即时调整每行的预览图片数量（最多 8 张）。

### 书签订阅
- 支持订阅书签 (任意搜索关键词、高级搜索条件等)，逻辑类似于原版订阅。
- 通过侧边栏原版“订阅”按钮下方新增的“书签订阅”按钮进入界面。
- 通过书签栏设定中的“订阅”按钮，对已有书签进行订阅。

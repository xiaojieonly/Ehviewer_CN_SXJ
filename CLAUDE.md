## Architecture Overview

Single Android app module (`app/`) with namespace `com.hippo.ehviewer`. Mixed Java/Kotlin codebase — Java is the legacy base; new code is gradually migrated to Kotlin.

- **Min SDK 23 / Target SDK 30 / Compile SDK 35**
- **Build variants**: `appReleaseDebug` / `appReleaseRelease`
- **ViewBinding** enabled; no Jetpack Compose

### Core Entry Points

| Class | Role |
|---|---|
| `EhApplication` | App singleton; initializes OkHttp client, `Conaco` image loader, `DownloadManager`, cookie store |
| `Settings` | Centralized `SharedPreferences` wrapper — all user preferences go through here |
| `EhDB` | GreenDAO database access object |
| `EhActivity` | Base `AppCompatActivity`; applies edge-to-edge window policy and theme on every `onCreate`/`onResume` |
| `MainActivity` | Navigation host; manages scene back-stack |

### UI Layer — Activity/Scene Pattern

The UI uses a custom scene system, not Jetpack Navigation. Scenes are Fragment-like views loaded inside `MainActivity` (or standalone Activities).

Key scenes under `ui/scene/`:
- `GalleryListScene` — browse/search gallery list
- `GalleryDetailScene` — gallery detail page
- `DownloadsScene` — local download management
- `HistoryScene` — browsing history
- `FavoritesScene` — E-H favorites
- `GalleryCommentsScene`, `GalleryPreviewsScene`, `GalleryInfoScene`
- `SignInScene`, `CookieSignInScene`, `WebViewSignInScene`

Standalone activities for settings, hosts config, filters, tags, etc.

### Network Layer (`client/`)

- `EhClient` — OkHttp 3.14.7 client wrapper; handles cookies via `EhCookieStore`, DNS via `EhProxySelector`
- `EhEngine` — high-level E-H API methods (search, detail fetch, favorites, comments, ratings, etc.)
- `EhRequestBuilder` — constructs OkHttp requests with proper headers
- `EhUrl` — URL construction constants
- `client/parser/` — HTML parsers using jsoup/TagSoup for every server response type
- `client/data/` — plain data models (`GalleryInfo`, `GalleryDetail`, `GalleryPreview`, etc.)

### Gallery Viewing (`spider/`)

The gallery reader works via three cooperating classes:
- `SpiderQueen` — coordinates page fetch workers; caches pages to disk; notifies the GL gallery view
- `SpiderDen` — manages the per-gallery file storage (downloaded images on disk)
- `SpiderInfo` — serialized metadata for a gallery download session

The gallery view itself is rendered via the native `glgallery` library (`com.github.seven332:glgallery`).

### Image Decoding (JNI/C++)

Custom image pipeline in `app/src/main/cpp/`:
- Decodes JPEG (libjpeg-turbo), PNG (libpng), GIF, WebP (libwebp), APNG natively
- Exposed to Java/Kotlin via `com.hippo.lib.image.Image` and `Native.kt`
- `Conaco` (`com.hippo.conaco`) is the in-app image loading/caching library (memory + disk via `beerbelly`)

### Download System

- `DownloadManager` — manages download queue, labels, and state
- `DownloadService` (Kotlin) — foreground service driving downloads
- `DownloadTorrentManager` (Kotlin) — torrent archive downloads

### Database

GreenDAO ORM (`org.greenrobot:greendao:3.0.0`). Schema is generated by the `daogenerator/` module. `EhDB` wraps all DAO access.

### Events

GreenRobot EventBus 3.3.1 is used for cross-component communication (e.g., `FavouriteStatusRouter`).

## Active Development: M001 — Edge-to-Edge / Transparent System Bars

The current milestone adds transparent status/navigation bars with proper inset handling. Key contracts:

- **`EhActivity.applyEdgeToEdgeWindowPolicy()`** — centralized `WindowCompat.setDecorFitsSystemWindows(false)` call; all activities inherit this
- **`WindowInsetHelper`** (`ui/inset/`) — idempotent helper that snapshots baseline padding/margins once, then reapplies system bar offsets on every inset dispatch to avoid offset stacking
- **`BottomOverlayInsetHelper`** (`ui/inset/`) — dedicated seam for bottom overlays (FABs, footer buttons) in Downloads and similar scenes
- Verification scripts: `scripts/verify-s01-foundation.sh` through `scripts/verify-s04-integration.sh`

**Inset rule**: Apply safe-area offsets through `WindowInsetHelper` or explicit host inset dispatch. Do **not** use `fitsSystemWindows=true` on scene roots — it conflicts with the edge-to-edge policy set in `EhActivity`.

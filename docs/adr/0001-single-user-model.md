# 0001: 单用户模型

本项目的同步、部署与备份设计均以**单一用户**为假设前提；服务器端保留 per-user 隔离代码（username 列、adoptNullOwnership）作为安全纵深，但产品上不面向多用户场景，也不为多用户冲突仲裁投入开发。

决策背景：AnotherViewer 是个人自用工具（个人服务器 + 个人平板/手机），部署形态为"自己从 GitHub 下载 zip 自己跑"。多设备属于同一用户的不同终端，任何设备上的变更都是该用户的意图，last-write-wins 覆盖即可视为"完全同步"，不存在需要仲裁的跨用户冲突。

推论：
- Filter 本地无时间戳，push 恒 `now` 是可接受的（同用户下后同步者即最新意图）
- preferences always-overwrite 语义成立（后同步设备设置即最终设置）
- 备份/还原/迁移只服务单一数据拥有者

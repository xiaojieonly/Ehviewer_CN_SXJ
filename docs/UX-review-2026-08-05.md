## Findings

### F-UX1（P2）历史网格卡标题与「last viewed」时间戳重叠
- 现象：dark-history 5 卡全部标题行与时间戳行叠印（home 同卡无时间戳则干净）。
- 根因方向：history 视图给网格卡注入 last-viewed 行，但网格卡 meta 区未为其预留行高/绝对定位冲突。
- 定位：`web-frontend/src/views/HistoryView.vue`（网格卡时间戳注入）× `web-frontend/src/components/gallery/GalleryCard.vue`（grid meta 布局）。
- 建议：grid 模式 meta 区改为流式两行（标题+次行），次行存在时撑高；或时间戳改入标题行尾省略。补 vitest 快照/行高断言。

### F-UX3（P3）FilterPanel 底栏遮盖 ADVANCED OPTIONS 标题，无滚动提示
- 现象：面板内容可滚但 sticky footer 直接压住最后一节标题，用户不知可滚。
- 定位：`web-frontend/src/components/search/FilterPanel.vue`。
- 建议：滚动容器加 bottom padding=footer 高+渐变 scroll cue（或 footer 上阴影随 scrollTop 出现）。

### F-UX4（P3）admin·高级 数据区 TODO 徽章与「清除」图标误读
- 现象：导出数据/导入数据行显示 TODO 徽章（备份 export/restore REST 已存在，WebUI 未接）；清除本地数据右侧图标形似永久 loading  spinner。
- 定位：`web-frontend/src/views/settings/AdminAdvanced.vue`。
- 建议：二选一——接入既有 `/api/v1/backup` export/restore（推荐，R4-5 契约在位）或隐藏两行；清除图标换 trash/eraser 语义图标。

### F-UX5（P3）收藏 tab 0 语义与 slot 徽章待查
- 现象：种子 slot=2/5/0/9 的四条全列于 Favorites 0（`FavoriteService.kt:22` `slot<=0→all` 文档化语义），且卡上 slot 徽章全显 ♥0。
- 问题：①app 侧页签按 slot 分（tab0=默认夹 -1+0），web「tab0=全部」分歧；②徽章全 0 需查是 push 路径丢 favoriteSlot 还是徽章渲染取 defaultFavoriteSlot。
- 定位：`anotherviewer-web/.../FavoriteService.kt:22`、`web-frontend/src/views/FavoriteView.vue`、`GalleryCard.vue` 徽章源。
- 建议：tab0 过滤 `favoriteSlot in (-1,0)`、tabN==N（对齐 app）；徽章显示条目真实 slot；若 push 丢 slot 则补 DTO/测试。

### F-UX6（可选缺口）§3.1 PC 增强未实现
- 卡片 hover 快捷操作（收藏/下载/详情）与右键菜单缺失；现 hover 仅标题微变调。键盘 `/`、`f` 已实现。
- 建议（若立项）：hover 浮现操作条（复用 FabLayout 图标语义）+ `@contextmenu` 菜单（详情/收藏/下载/复制链接），PC 形态专属，不进 <720。
